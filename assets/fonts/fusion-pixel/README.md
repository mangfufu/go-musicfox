# Fusion Pixel 像素字体

本目录包含 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 的简体中文 12px 等宽字体。英文为半宽，中文为全宽，适合终端中英混排。

- 字体家族：`Fusion Pixel 12px Mono zh-Hans`
- 版本：`2026.10.16`
- 原始发布包：[fusion-pixel-font-12px-monospaced-otf-v2026.10.16.zip](https://github.com/TakWolf/fusion-pixel-font/releases/download/2026.10.16/fusion-pixel-font-12px-monospaced-otf-v2026.10.16.zip)
- 发布包 SHA-256：`42082847da7973b03d666bf6e47d3bd40d5a973e8d0f8ad286d321e6602c916d`
- 本目录 OTF SHA-256：`c557a18bf3540a318a0dee16ca5eec5370f0455d0e050f68cc09a667d94a5ca6`

字体未经修改，按 SIL Open Font License 1.1 分发；许可证见 `OFL.txt`，原字体组件许可证见 `LICENSES/`。这些字体采用自身的许可证，不适用项目源码许可证。

运行根目录 `Setup-PixelFont.ps1` 为当前 Windows 用户安装字体和专用 Windows Terminal 配置。其他系统可自行安装 OTF，并将终端字体设置为上述家族。完整启动说明见 [磁带视图文档](../../../docs/cassette-view.md)。
